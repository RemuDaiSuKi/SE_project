# Design

## Context

SpecKit 組的老師端功能已經完成並驗證（`silverwind63/SEFinal`，2026-11-23 的 `main`）。本 change 以對方的實際程式行為為準來調整本 repo；對方的規格與程式行為有出入時，以程式為準（例如對方的頁面有只清除瀏覽器 Token 的登出按鈕）。

## Decisions

### D1 對齊的層級：操作結果，不是識別名稱

對齊的是老師與助教觀察得到的結果：
- 接受或拒絕
- 填空格位置、原始題號、子題標籤、題組
- 錯誤數量
- 鎖定次數與秒數、Token 時效
- 結構檢查是否通過
- 伺服器能否啟動

環境變數前綴（`BUZZER_` 與 `GB_`）、指令名稱、API 路徑與錯誤訊息用字不改：改了會讓既有文件與搶答活動 change 的交接全部失效，而且不影響操作結果。

### D2 以差異測試驗證

在比對用的 harness 中，同一份 Sheets API 回應同時餵給兩邊的解析器，比較正規化後的結果：
- 2 份範例學習單
- 18 種特殊排版
- 15,000 份隨機學習單（3 組亂數種子）

結果全部一致。寫回前的結構檢查另以 7 種情境比對：未修改、工作表改名、填空格已有內容、子題標籤被改、插入一列、刪掉題目文字、原始題號被改。

### D3 讀取顯示值

`FETCH_FIELDS` 改為要求 `formattedValue`，`grid_from_sheets_api` 只保留非空字串，所以格子資料的值一律是字串。

後果與 SpecKit 組相同：顯示為空白的公式格會被當成填空格，寫回時以 RAW 覆蓋該公式。

### D4 填空格以「空白區段」計算

作答範圍內屬於該列的儲存格依欄順序走訪：合併範圍算一格，被上方或左方合併覆蓋的格子略過。

遇到空白格、且前一格不是空白時，開始一個新的區段。恰好一個區段才合法，填空格是該區段最左邊的儲存格。

### D5 題組範圍與題目列

題號欄範圍內的縱向合併只要涵蓋表頭以下兩列以上，涵蓋的每一列都必須是題目列。每個非題目列各產生一處問題，與 SpecKit 組的錯誤數相同。

題目列只看位在該列本身的儲存格，因此縱向合併的題目格只屬於最上面那列。

### D6 預覽改存 SQLite

schema 第 3 版只新增 `worksheet_previews` 資料表，欄位為 `preview_id`、試算表識別、`parsed_json`、`status`、`created_at`，第 2 版的學習單不受影響。

`PreviewStore.confirm(id, save)` 在同一把鎖內完成三件事：讀取待確認的預覽、建立學習單、把預覽標為已確認。這樣同一份預覽不會被確認兩次。

### D7 寫回前的結構檢查

比對欄位為 `(sheet_id, sheet_name, cell_ref, group_no)` 加上題數，重新解析時使用目前設定的標籤與題數上限。遇到第一個差異就以單一明細回報，API 仍回 409「學習單結構與匯入時不一致，無法寫回」。

寫入範圍使用匯入時保存的工作表名稱。

### D8 老師登入鎖定

新增 `LoginLimiter`，所有視窗共用一個計數：
- 達到上限時鎖定，並把計數歸零。
- 鎖定期間連正確密碼也拒絕。
- 登入成功時計數歸零。

`WindowRegistry` 仍負責發放視窗識別，它的鎖定功能保留給組別代碼使用。

### D9 啟動檢查

`python -m app` 依序檢查三件事，任何一項不符就輸出繁中說明並以結束碼 1 結束：
1. 老師密碼
2. OAuth 用戶端設定檔是否存在
3. 授權檔是否可載入且有更新權杖

`create_app` 本身不做 Google 檢查，測試可以注入假的存取層。

## Diagrams

本 change 修改的圖（原始檔）：
- `diagrams/class.puml`：PreviewStore 的方法與保存方式、`GoogleAuth.account()`、SheetsError 的分類
- `diagrams/sequence-import.puml`：讀取顯示值、預覽存入資料庫、確認或取消已結束預覽的 409
- `diagrams/sequence-writeback.puml`：使用目前設定的標籤、比對欄位
- `diagrams/component.puml`：監聽位址、移除 google 路由、LoginLimiter

## Risks

- 監聽位址設成 127.0.0.1 以外、又沒有 Host 檢查時，同網路的其他電腦可以連線。預設值仍是 127.0.0.1，README 註明。
- 顯示值會受試算表的數字格式影響，例如題號顯示成「1.0」時原始題號就是「1.0」。這與 SpecKit 組相同。

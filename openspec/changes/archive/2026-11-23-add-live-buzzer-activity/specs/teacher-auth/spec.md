# Spec Delta

## MODIFIED Requirements

### Requirement: 老師專屬操作
以下操作 SHALL 只允許持有效老師 Token 的請求：
- 匯入學習單、確認或取消匯入、查看學習單
- 建立活動、查看活動清單與活動監看畫面
- 切換活動階段、判定無效、重新產生組別代碼
- 寫回答案與匯出 CSV

其他請求 MUST 被拒絕並回應「無權限執行此操作」，且 MUST NOT 產生任何副作用。

#### Scenario: 未登入者呼叫老師功能
- **WHEN** 沒有 Token 的請求呼叫學習單匯入、寫回或 CSV 匯出
- **THEN** 系統回應「無權限執行此操作」，不建立、不修改、不回傳任何資料

#### Scenario: 非老師身分呼叫老師功能
- **WHEN** 持非老師 Token（例如學生 Token）的請求呼叫任何老師專屬操作
- **THEN** 系統回應「無權限執行此操作」，不產生任何副作用

#### Scenario: 學生呼叫活動管理功能
- **WHEN** 持 A 組 Token 的請求呼叫建立活動、開始、結束、判定無效、重新產生代碼或查看活動監看畫面
- **THEN** 系統回應「無權限執行此操作」，活動狀態、代碼與送出紀錄都不變
